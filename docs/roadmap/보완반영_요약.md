# 보완 반영 요약 (4개 영역)

앞선 리뷰의 4개 영역을 반영했다. 각 항목의 **적용 위치**와, 아직 남은 **결정/자격증명 자리(seam)** 를 함께 정리한다.

## ① 운영 안정성
| 항목 | 적용 | 비고 |
|---|---|---|
| 멈춘 job 회수(stale reaper) | `worker.py::reap_stale` | `STALE_SECONDS` 초과 processing → 재큐, `MAX_ATTEMPTS` 초과 시 데드레터(error) |
| 엔진 호출 재시도+backoff | `worker.py::call_engine` | `ENGINE_RETRIES`, 지수 backoff |
| 시도 횟수 추적 | `jobs.attempts` (+claim 시 증가) | events 에 `claimed{attempt}`·`reaped` |
| 실제 인증 경계 | gateway `AUTH_MODE=strict` | X-User-Id 없으면 401. **상류(프록시/미들웨어)가 JWT 검증 후 주입** — 그 계층은 도입 필요(seam) |
| 마이그레이션 | `deploy/db/migrations/0001_init.sql` + gateway `AUTO_DDL`(dev만) | 운영은 SQL 적용, auto-DDL off |
| 스토리지 추상화 | gateway `storage.py` (local/supabase) | local 동작. **SupabaseStorage 는 구현 자리**(SUPABASE_URL/KEY) |

## ② 정확성·유효성
| 항목 | 적용 | 비고 |
|---|---|---|
| 얼굴/ROI 검출 | analysis `roi.py`(Haar) + `model.py` 크롭 | 실패 시 중앙 크롭. landmark/segmentation 로 교체 여지 |
| 엔진 출력 스키마 검증 | analysis `AnalysisOut`, prescription `PrescribeOut`(pydantic) | 필드 드리프트 차단 |
| 파트별 단위 테스트 | `tests/{common,gateway,worker,engine_analysis,engine_prescription}` (43건) | 계약·검증·인증·스토리지·로깅·재시도·ROI·지표·규칙·엔드포인트. `make test` |
| 통합 테스트(DB) | `tests/integration/*` (2건) | gateway/analyze→worker→prescriptions 기록·단계순서·리퍼. 임시 Postgres. `make itest` |
| CI 테스트 잡 | `.github/workflows/tests.yml` | unit + integration(postgres 서비스) 2잡 |

## ④ 도메인
| 항목 | 적용 | 비고 |
|---|---|---|
| prescriptions 테이블 + `prescribed` 상태 | 스키마/마이그레이션 + `worker.finish_ok` | 처방 1건 별도 기록, status processing→prescribed→done |
| 리포트 생성 | gateway `GET /jobs/{id}/report`(HTML) | **최소 placeholder** — Word/Excel/브랜디드 HTML 로 교체 자리 |
| 종합 vs 지표별 비율 | 둘 다 제공(종합 `grade`/`ratio` + `per_metric`) | **최종 산출 규칙 미확정(도메인 결정)** |
| PCR 매핑 | `mixes.json` `pcr_to_mixes` | placeholder — 실제 마커→PM 규칙 필요 |

## 아직 당신이 채울 자리(seam) 정리
- 상류 **인증 계층**(JWT 검증 → X-User-Id 주입)
- **SupabaseStorage** 구현(presigned 업로드/다운로드) + worker 의 서명 URL fetch
- 분석 **점수식·정규화 상수·가중치**, 설문 문항·척도
- **믹스 배합/선택 규칙**(엑셀 → `mixes.json`), PCR 매핑
- **종합 vs 지표별 처방** 최종 규칙
- **고객 리포트** 문서 생성기

새 환경변수: `AUTH_MODE`(dev|strict), `AUTO_DDL`, `STORAGE_BACKEND`(local|supabase),
`MAX_ATTEMPTS`, `STALE_SECONDS`, `ENGINE_RETRIES`, `ENGINE_MODEL`(baseline|ml), `LOG_LEVEL`.
