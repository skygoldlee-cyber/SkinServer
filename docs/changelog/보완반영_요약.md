# 보완 반영 요약 (4개 영역)

앞선 리뷰의 4개 영역을 반영했다. 각 항목의 **적용 위치**와, 아직 남은 **결정/자격증명 자리(seam)** 를 함께 정리한다.

## ① 운영 안정성
| 항목 | 적용 | 비고 |
|---|---|---|
| 멈춘 job 회수(stale reaper) | `worker.py::reap_stale` | `STALE_SECONDS` 초과 processing → 재큐, `MAX_ATTEMPTS` 초과 시 데드레터(error) |
| 엔진 호출 재시도+backoff | `worker.py::call_engine` | `ENGINE_RETRIES`, 지수 backoff |
| 시도 횟수 추적 | `jobs.attempts` (+claim 시 증가) | events 에 `claimed{attempt}`·`reaped` |
| **DB 커넥션 풀** | gateway/worker `psycopg-pool`(`ConnectionPool`) | 요청·이벤트마다 연결을 새로 열지 않고 재사용. gateway `DB_POOL_MIN=2`/`DB_POOL_MAX=10`, worker `2`/`5`. `psycopg-pool==3.2.4` 핀 |
| **워커 임시파일 정리** | `worker/storage.py` `is_temp` + `worker.py` `finally` | supabase 백엔드가 남긴 tmpfs 임시파일 누수 차단(OOM 방지). 로컬 원본은 보존 |
| **워커 다운로드 상한** | `worker/storage.py` 스트리밍 + `MAX_DOWNLOAD_BYTES`(기본 25MB) | 버킷 `file_size_limit`(SQL)과 함께 심층 방어. 초과 시 `ValueError` |
| 실제 인증 경계 | gateway `AUTH_MODE=strict` | X-User-Id 없으면 401. **`ENV=prod`+`AUTH_MODE!=strict` 기동 거부(fail-fast) + JWT iss 고정(`JWT_ISS`/`SUPABASE_URL`) 적용됨** |
| 마이그레이션 | `deploy/db/migrations/0001_init.sql` + gateway `AUTO_DDL`(dev만) | 운영은 SQL 적용, auto-DDL off |
| 스토리지 추상화 | gateway `storage.py` (local/supabase) | local 동작. **SupabaseStorage 실구현 완료(presigned 발급/서명 URL)** — Phase 4 반영 |

## 아직 당신이 채울 자리(seam) 정리
- 상류 **인증 계층**(JWT 검증 → X-User-Id 주입)
- **SupabaseStorage** 구현(presigned 업로드/다운로드) + worker 의 서명 URL fetch
- 분석 **점수식·정규화 상수·가중치**, 설문 문항·척도
- **믹스 배합/선택 규칙**(엑셀 → `mixes.json`), PCR 매핑
- **종합 vs 지표별 처방** 최종 규칙
- **고객 리포트** 문서 생성기

새 환경변수: `AUTH_MODE`(dev|strict), `AUTO_DDL`, `STORAGE_BACKEND`(local|supabase),
`MAX_ATTEMPTS`, `STALE_SECONDS`, `ENGINE_RETRIES`, `ENGINE_MODEL`(baseline|ml), `LOG_LEVEL`.

보안·안정화(코드리뷰 1-1/2-1/2-2/2-3)로 추가된 환경변수:
`DB_POOL_MIN`·`DB_POOL_MAX`(커넥션 풀 크기, gateway·worker 별도 기본값), `MAX_DOWNLOAD_BYTES`
(워커 다운로드 상한, 기본 25MB), `JWT_ISS`(JWT 발급자 고정, 미설정 시 `SUPABASE_URL/auth/v1`),
`SUPABASE_URL`·`SUPABASE_SERVICE_KEY`·`STORAGE_BUCKET`(Supabase 스토리지), `ENABLE_LEGACY_UPLOAD`·
`PRESIGN_EXPIRES_SEC`·`PRESIGN_RATE_PER_MIN`(Phase 4 presigned). 각 서비스 기본값이 있어
compose 명시 배선 없이도 동작한다(기본값으로 수렴).
