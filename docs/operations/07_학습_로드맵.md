세트의 **옛 번호 순서(04→01→02→03→05)** 는 성격별 분류(계보)이고, 이 문서는 **학습 의존성 순서**입니다.

아래 문서 경로는 현재 monorepo 기준입니다(옛→현재 매핑은 `../README.md`).

**두 갈래로 쓰세요**

- **실제 구축:** 아래 단계를 순서대로 손으로 따라가되, 각 단계를 **이야기(개념) → 가이드/런북(실습) → 06 체크리스트(점검)** 의 3겹으로 도세요.
